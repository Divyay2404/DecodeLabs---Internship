# 🤖 Rule-Based AI Chatbot | DecodeLabs Project 1

## Overview
A rule-based chatbot built using Python control flow and
dictionary-based intent matching. Built as Project 1 of the
DecodeLabs AI Industrial Training — Batch 2026.

## Features
- ✅ Continuous input loop (while True)
- ✅ Input sanitization (lower + strip)
- ✅ Dictionary knowledge base — O(1) lookup
- ✅ Fallback for unknown inputs
- ✅ Clean exit strategy (bye/exit/quit)
- ✅ Live time and date responses

## How to Run
    python chatbot.py

## Tech Stack
- Python 3.x
- Modules: random, datetime

## Key Concepts Used
- Control Flow (if-else, while loop)
- Dictionary O(1) lookup vs if-elif O(n) ladder
- IPO Model: Input → Process → Output
- Input sanitization and normalization
